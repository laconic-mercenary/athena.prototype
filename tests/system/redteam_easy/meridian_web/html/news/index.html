Migrating our configuration service to Python and Flask

By the Meridian Platform Team · July 2026

Over the last quarter we rebuilt Meridian's internal configuration portal on a modern Python stack. The new service is a lightweight Flask application that accepts configuration documents, validates them, and applies them across environments — replacing the aging Java service our customers' platform teams had outgrown.

Moving to Python let us iterate faster and lean on the ecosystem our engineers already know. The portal parses submitted YAML configuration server-side and returns a normalized result, which made the migration path for existing customers straightforward.

Open client tooling

As part of the rollout we've published an open-source client library so customer platform teams can integrate the config portal into their own pipelines. It wraps the portal's submission API and ships with example environment definitions.
